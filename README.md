# TactiQ ($TDNA)

**Tactical DNA matchup prediction engine for FIFA World Cup 2026.**

TactiQ ingests granular football event data, engineers tactical style vectors per national team, clusters teams into playing archetypes, and predicts match outcomes from style-vector matchups using XGBoost — with SHAP explanations and an upset detector surfaced in a Streamlit dashboard.

Setup instructions coming in Phase 8.
